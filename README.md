# Web Portfolio Construction

SIW 高度専門士情報技術科の高窪真拓（学籍番号: 24010020）が制作・運用する個人ポートフォリオサイトです。

## 🌐 ライブプレビュー
* [ポートフォリオサイトを見る](https://nyan48310-code.github.io/-/)

## 💡 概要
プロジェクトマネジメントの手法や論理的思考（ロジカルシンキング）を軸に、自身のスキルセットおよび制作した企画提案書（Projects & Works）を紹介するWebサイトです。スマートフォンとPCの双方で快適に閲覧できるレスポンシブデザインと、軽量で高速な表示パフォーマンスを追求しています。

## 🛠 使用技術・ツール
* **言語:** HTML5, CSS3
* **フォント:** Google Fonts (Inter, Noto Sans JP)
* **デザイン・スライド:** Canva
* **バージョン管理:** Git / GitHub

## 📂 セクション構成
1. **ABOUT ME** - 自己紹介および所属・専門領域
2. **STRENGTHS** - PMに関する3つのコア強み（推進力、問題切り分け、言語化・サポート）
3. **PROJECTS & WORKS** - 小型ドローンの社会運用に関する企画提案書（Canvaスライド）の紹介
4. **CONTACT** - GitHubプロフィールへのリンク
